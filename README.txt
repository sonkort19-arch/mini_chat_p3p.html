MINI CHAT V4 MAX — GITHUB + VERCEL

Это крупное обновление проекта без Supabase, VPS и других сервисов.

ОСНОВНОЕ
- один WebSocket держит несколько сохранённых комнат;
- локальная история на телефоне/компьютере через IndexedDB;
- текст, фото, видео, голосовые и файлы сохраняются локально;
- автоматическое переподключение;
- серверная часть не записывает историю сообщений в базу или файл.

ЗАЩИЩЁННАЯ ПЕРЕДАЧА
- браузеры создают ECDH P-256 ключи для текущего соединения;
- общий ключ используется для AES-GCM;
- текст, профиль, реакции, правки, команды удаления и содержимое файлов передаются в зашифрованном виде;
- сервер всё равно видит служебные данные соединения: код комнаты, размеры/частоту пакетов и факт обмена;
- PIN приложения блокирует интерфейс, но не шифрует IndexedDB.

ЧАТЫ
- несколько чатов онлайн одновременно;
- непрочитанные;
- архив;
- закрепление;
- беззвучный режим;
- свои названия чатов;
- имя и аватар профиля;
- в сети / последнее появление;
- «печатает…»;
- локальные черновики;
- общий поиск по локальной истории;
- поиск внутри чата.

СООБЩЕНИЯ
- ответы;
- свайп по сообщению для ответа;
- реакции emoji;
- редактирование своих текстовых сообщений;
- удалить у себя;
- удалить у обоих, когда второй клиент получает команду;
- пересылка в другой чат;
- избранные сообщения;
- статусы отправлено / доставлено / прочитано;
- отправка геопозиции.

МЕДИА И ФАЙЛЫ
- камера;
- фото;
- видео;
- голосовые с таймером и отменой;
- обычные файлы;
- вставка изображения из буфера обмена;
- drag & drop на компьютере;
- галерея вложений;
- лимит одного файла: 15 МБ.

НАСТРОЙКИ
- светлая / тёмная / системная тема;
- размер текста;
- уведомления;
- звук;
- вибрация;
- badge непрочитанных;
- локальный PIN;
- ручная блокировка;
- автоблокировка 1 / 5 / 15 минут;
- автоочистка локальной истории 7 / 30 / 90 дней;
- запрос persistent storage;
- диагностика соединения и шифрования.

РЕЗЕРВНАЯ КОПИЯ
- экспорт всей локальной истории;
- перенос на другой телефон/компьютер;
- необязательный пароль;
- если пароль указан, файл резервной копии шифруется AES-GCM с ключом из PBKDF2-SHA256.

КАК ОБНОВИТЬ
1. Распакуй ZIP.
2. Открой текущий репозиторий Mini Chat на GitHub.
3. Upload files.
4. Перетащи ВСЁ содержимое распакованной папки в корень репозитория.
5. Commit changes.
6. Vercel автоматически создаст новый Deploy.
7. После Deploy полностью закрой старую версию Mini Chat на телефоне и открой её заново.
8. Если виден старый дизайн, обнови страницу ещё раз, чтобы обновился Service Worker.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Сервер не хранит сообщения. Поэтому файл нельзя надёжно доставить человеку, который полностью офлайн.
- Текст, написанный офлайн, остаётся локально и приложение пытается переслать его после восстановления защищённого соединения.
- Если iPhone полностью выгрузил приложение, WebSocket перестаёт работать. Полноценные push-уведомления при полностью закрытом приложении без постоянного хранилища push-подписок не гарантируются.
- История автоматически не синхронизируется между разными устройствами; для переноса есть резервная копия.
