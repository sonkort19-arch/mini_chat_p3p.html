MINI CHAT — GITHUB + VERCEL

Что делает проект:
- комнаты по 6-значному коду;
- текстовые сообщения;
- фото;
- видео;
- голосовые сообщения;
- базы данных нет;
- приложение не сохраняет историю переписки;
- при закрытии/обновлении страницы история в браузере исчезает;
- автоматическое переподключение WebSocket.

КАК ЗАПУСТИТЬ

1. Создай новый репозиторий на GitHub.
2. Загрузи ВЕСЬ контент этой папки в корень репозитория.
   В корне должны быть:
   - app
   - public
   - package.json

3. Открой Vercel.
4. Нажми Add New -> Project.
5. Выбери репозиторий GitHub с Mini Chat.
6. Ничего в настройках сборки не меняй.
7. Нажми Deploy.
8. После завершения открой ссылку *.vercel.app.

ВАЖНО
- Это новый Vercel-проект, поэтому Fluid Compute обычно включен по умолчанию.
- WebSocket-функция имеет ограничение по длительности выполнения Vercel.
  В приложении предусмотрено автоматическое переподключение.
- Для микрофона на iPhone нужна HTTPS-страница. Ссылка Vercel уже использует HTTPS.
- Отправка файлов ограничена приложением до 25 МБ.
- Комнаты хранятся только в оперативной памяти текущей Vercel Function, а не в базе.
