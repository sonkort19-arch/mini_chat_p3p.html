MINI CHAT V3 PRO — GITHUB + VERCEL

Это обновление заменяет V2. Дополнительные сайты и база данных не нужны.

ГЛАВНОЕ
- Один WebSocket держит сразу все сохранённые комнаты.
- Пока приложение открыто/работает в фоне, сообщения могут приходить из других чатов.
- Сервер Vercel не сохраняет историю переписки.
- История и медиа хранятся локально на конкретном телефоне/компьютере.

НОВОЕ В V3 PRO
1. Несколько чатов онлайн одновременно.
2. Профиль: имя и локальный аватар.
3. Локальное имя контакта/чата.
4. Закреплённые чаты.
5. Архив.
6. Беззвучные чаты.
7. Непрочитанные и badge приложения.
8. Онлайн / последнее появление.
9. "печатает…".
10. Ответ на сообщение.
11. Реакции emoji.
12. Редактирование своих текстовых сообщений.
13. Удаление своего сообщения у обоих, если второй клиент получает команду.
14. Поиск по конкретному чату.
15. Общий поиск по локальной истории.
16. Фото и видео.
17. Камера телефона.
18. Обычные файлы.
19. Голосовые с таймером и отменой.
20. Вставка изображения из буфера обмена на компьютере.
21. Локальная история через IndexedDB.
22. Текст, фото, видео, голосовые и файлы хранятся локально.
23. Автоудаление локальной истории через 7 / 30 / 90 дней или без ограничения.
24. Резервная копия всей локальной истории в JSON.
25. Восстановление истории из резервной копии.
26. Светлая / тёмная / системная тема.
27. Уведомления, звук, вибрация.
28. PWA и установка на главный экран.
29. Запрос persistent storage для лучшей защиты локальных данных.
30. Автоматическое переподключение к Vercel.

КАК ОБНОВИТЬ
1. Распакуй ZIP.
2. В текущем GitHub-репозитории Mini Chat замени старые файлы содержимым этой папки.
3. Commit changes.
4. Vercel автоматически сделает новый Deploy.
5. После Deploy на телефоне полностью обнови страницу. Если приложение добавлено на главный экран, иногда полезно закрыть его и открыть заново.

ВАЖНО
- История одного телефона не появляется автоматически на другом устройстве. Для переноса есть резервная копия.
- Полностью закрытое приложение не может держать WebSocket. Поэтому push как у WhatsApp при полностью выгруженном приложении без отдельного хранилища push-подписок не реализован.
- Фото/видео/файлы ограничены 20 МБ на одну отправку.
- Комнаты защищены только шестизначным кодом. Не используйте Mini Chat для критически конфиденциальной информации.
