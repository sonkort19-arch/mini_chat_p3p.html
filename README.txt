MINI CHAT V2 — GITHUB + VERCEL

Обновление V2:
- интерфейс ближе к обычному мессенджеру;
- локальная история на конкретном телефоне/компьютере через IndexedDB;
- текст, фото, видео и голосовые сохраняются локально;
- список последних чатов;
- непрочитанные сообщения и счётчик;
- статусы сообщения: отправляется / отправлено / доставлено / прочитано;
- статус "печатает…";
- звук и вибрация;
- уведомления, пока веб-приложение открыто или работает в фоне;
- PWA: можно добавить на главный экран;
- запрос постоянного локального хранилища;
- очистка и удаление локальной истории;
- сервер Vercel по-прежнему НЕ записывает переписку в базу.

КАК ОБНОВИТЬ ТЕКУЩИЙ ПРОЕКТ

1. Распакуй ZIP.
2. В GitHub открой свой текущий репозиторий Mini Chat.
3. Замени содержимое репозитория содержимым этой папки.
4. Сохрани изменения (Commit changes).
5. Vercel сам увидит обновление GitHub и сделает новый Deploy.
6. После Deploy обнови страницу приложения.

ВАЖНО ПРО ЛОКАЛЬНУЮ ИСТОРИЮ
История хранится именно в браузере конкретного устройства.
Она не синхронизируется автоматически между телефоном и компьютером.
Если удалить данные сайта/браузера, локальная история может быть удалена.
В Настройки -> "Защитить локальную историю" приложение запросит persistent storage,
если браузер это поддерживает.

ВАЖНО ПРО УВЕДОМЛЕНИЯ
В этой версии уведомления работают, когда страница/PWA ещё запущена и получает сообщения.
Полноценные push-уведомления при полностью закрытом приложении требуют Web Push подписки
и дополнительной серверной логики/секретного VAPID-ключа. Это специально не добавлено,
чтобы проект продолжал работать только через GitHub + Vercel без дополнительной базы.
